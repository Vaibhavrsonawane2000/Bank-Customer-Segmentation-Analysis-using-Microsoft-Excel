# Bank-Customer-Segmentation-Analysis-using-Microsoft-Excel
# Problem Overview
This project analyzes over 105,000 banking customers using Microsoft Excel. The objective is to segment customers based on demographic and behavioral attributes, identify valuable customer groups, and recommend marketing strategies using interactive dashboards.

# Business Problem

Banks need to understand customer behavior to improve customer retention, increase cross-selling opportunities, and optimize marketing campaigns.

This project answers questions such as:

Which customer segments are most valuable?
Which customers are inactive?
Which occupations hold the highest account balances?
Which customer groups are more likely to own credit products?
How can marketing campaigns be personalized?

Project Workflow
# 1. Data Cleaning
Removed duplicate records
Handled missing values
Standardized text formatting
Validated data consistency

# 2. Customer Segmentation
Customers were segmented based on:

Gender
Age Group
Occupation
Region
Credit Product Ownership

PivotTables were used to analyze customer distribution across different demographic groups.

# 3. Customer Behavior Analysis

Calculated:

Average Account Balance
Average Customer Vintage
Credit Product Ownership Rate
Active vs Inactive Customers

# 4. Dashboard Development
Built an interactive Excel Dashboard using:

PivotTables
PivotCharts
KPI Cards
Conditional Formatting
Slicers
